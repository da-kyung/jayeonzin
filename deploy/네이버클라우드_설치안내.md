# 네이버클라우드 설치 안내 (도메인 없이 시작)

> 소요 시간: 약 30~40분 · 준비물: 결제 카드, Windows 또는 Mac 컴퓨터
> 네이버클라우드 화면 메뉴 이름은 개편으로 조금 다를 수 있습니다. 비슷한 이름을 찾아 진행하세요.

---

## 1단계. 가입 · 결제수단 등록 (5분)
1. https://www.ncloud.com 접속 → **회원가입** (개인 또는 법인)
2. **마이페이지 → 결제수단 관리**에서 카드 등록
   - 법인으로 가입하면 세금계산서 발행 가능
   - 신규 가입 크레딧/무료 혜택이 있는지 첫 화면 이벤트를 확인하세요

## 2단계. 서버 만들기 (10분)
1. 우측 상단 **콘솔** → 리전이 **한국(KR)** 인지 확인
2. **Services → Compute → Server → 서버 생성**
3. 선택 항목

   | 항목 | 선택 |
   |---|---|
   | 서버 이미지 | **Ubuntu 22.04** 또는 **24.04** |
   | VPC / Subnet | 처음이면 화면 안내에 따라 **새로 생성** (Subnet은 **Public**) |
   | 서버 사양 | 가장 작은 사양(예: 2vCPU / 4GB 이하)으로 충분 — 요금표 확인 후 선택 |
   | 스토리지 | 기본값 |
   | 공인 IP | **새로운 공인 IP 할당** 선택 (화면에 없으면 4단계에서 따로 신청) |

4. **인증키 설정** → "새로운 인증키 생성" → 이름 입력 → **`.pem` 파일 다운로드**
   - ⚠ 이 파일은 다시 받을 수 없습니다. 안전한 곳에 보관하세요.

## 3단계. 방화벽(ACG) 열기 (5분)
서버 생성 화면 또는 **Server → ACG** 메뉴에서, 이 서버의 ACG에 **Inbound 규칙** 3개를 추가합니다.

| 프로토콜 | 접근 소스 | 포트 | 용도 |
|---|---|---|---|
| TCP | **내 IP** (화면의 "myIp" 버튼) | 22 | 설치용 원격 접속 |
| TCP | 0.0.0.0/0 | 80 | HTTPS 인증서 발급 |
| TCP | 0.0.0.0/0 | 443 | 학부모 접속 |

> 22번은 "내 IP"만 열어두는 게 안전합니다. 다른 장소에서 접속할 땐 그때 추가하세요.

## 4단계. 공인 IP 확인 · 관리자 비밀번호 받기 (5분)
1. **Server** 목록에서 서버 상태가 **운영중**이 될 때까지 기다리기 (5분 내외)
2. 공인 IP가 없으면 **Server → Public IP → 공인 IP 신청** → 이 서버에 연결
3. 서버 선택 → **서버 관리 및 설정 변경 → 관리자 비밀번호 확인** → 2단계의 `.pem` 파일 첨부 → 비밀번호 복사해두기

## 5단계. 서버 접속 (3분)
- **Windows**: 시작 메뉴에서 **PowerShell** 실행
- **Mac**: **터미널** 실행

```
ssh root@공인IP
```
- "Are you sure you want to continue connecting?" → `yes` 입력
- 비밀번호 입력 (4단계에서 복사한 것. 입력해도 화면에 표시되지 않는 게 정상입니다)

## 6단계. 설치 (한 줄, 약 5분)
아래 한 줄을 복사해 붙여넣고 Enter:

```
curl -fsSL https://raw.githubusercontent.com/da-kyung/jayeonzin/claude/school-parent-communication-app-8ao6z5/deploy/install.sh | bash
```

설치 중 두 가지를 물어봅니다.
1. **입장 코드**: 학부모님들께 가정통신문으로 안내할 코드 (4자리 이상)
2. **운영자 비밀번호**: 8자 이상, 두 번 입력 (화면에 안 보이는 게 정상)

끝나면 이런 화면이 나옵니다.
```
✅ 설치 완료  (앱: 정상 실행 중)
접속 주소 :  https://203-0-113-7.sslip.io
```
> `203-0-113-7.sslip.io` 는 서버 IP로 자동으로 만들어지는 **무료 임시 주소**입니다. HTTPS(자물쇠)도 자동 적용됩니다.

## 7단계. 확인 · 초기 설정 (5분)
1. 휴대폰으로 접속 주소 열기 → 입장 코드 입력 → 화면 확인
2. **더보기 → 운영자 로그인**
3. **학교 홈페이지 연동**: 학교 홈페이지 공지사항 / 가정통신문 게시판 주소 붙여넣기 → **저장 후 가져오기** → `✓ 연결됨` 확인
4. 소통방 **공지**로 이용 수칙 올리고 📌 상단 고정
5. 휴대폰 **홈 화면에 추가** → 학부모 안내 시작

## 나중에 도메인을 샀을 때 (예: `dtg-parents.kr`)
1. 가비아·후이즈 등 도메인 업체에서 **DNS 설정 → A 레코드**: `@`(또는 `talk`) → **서버 공인 IP**
2. 10분~1시간 뒤, 서버에 접속해서:
   ```
   DOMAIN=dtg-parents.kr bash /opt/board/deploy/install.sh
   ```
   (기존 글·설정은 그대로 유지되고 주소만 바뀝니다. 새 주소를 다시 안내하세요.)

## 운영 중 자주 쓰는 명령 (서버 접속 후)
| 하고 싶은 일 | 명령 |
|---|---|
| 최신 버전으로 업데이트 | `bash /opt/board/deploy/update.sh` (실패하면 자동으로 이전 버전 복구) |
| 입장 코드·비밀번호 변경 | `nano /etc/board.env` → 수정 후 `Ctrl+O`, Enter, `Ctrl+X` → `systemctl restart board` |
| 동작 확인 / 로그 | `systemctl status board` · `journalctl -u board -n 50` |
| 백업 파일 | `/var/backups/board/` (매일 자동, 14일 보관) |

## 문제 해결
| 증상 | 확인할 것 |
|---|---|
| 주소가 안 열림 | ACG에 80·443 포트가 0.0.0.0/0 으로 열렸는지 · 1~2분 후 재시도 |
| `ssh` 접속 안 됨 | ACG 22번 포트의 "내 IP"가 지금 장소의 IP인지 (장소가 바뀌면 다시 추가) |
| 학교 홈페이지 연동 실패 | 운영자 화면의 실패 사유 확인 · 게시판 주소를 학교 홈페이지에서 다시 복사 |
| 입장 코드가 유출됨 | `/etc/board.env` 에서 `ACCESS_CODE` 변경 후 재시작 → 새 코드 재안내 (기존 접속자는 유지) |

## 비용 관련 주의
- 서버를 **반납(삭제)할 때 공인 IP도 반납**해야 요금이 완전히 멈춥니다.
- 서버를 "정지"해도 일부 요금(스토리지·공인 IP)은 계속 나갈 수 있습니다.
