# 동탄국제고 학부모 익명 소통방

학교 학부모끼리 **가입 없이, 익명으로** 질문·건의·정보를 나누는 모바일 웹앱입니다.
외부 패키지 없이 Node.js(22.13 이상) 하나로 동작합니다.

## 화면 구성 (메신저형)
- **소통방**: 채팅방 목록처럼 글이 보이고, 고정 공지는 상단 배너로 표시
- **대화방**: 원글이 첫 말풍선, 댓글이 대화처럼 이어짐 (내 메시지는 오른쪽, 운영자는 🏫 표시). 10초마다 새 답글 자동 반영. 말풍선을 누르면 복사·신고·삭제 메뉴
- **하단 메뉴**: 소통방 · 공지 · 글쓰기 · 내 활동 · 더보기(이용수칙, 홈화면 추가 안내, 운영자)

## 학교 홈페이지 연동 (공지사항 · 가정통신문)
- 운영자 화면(더보기) → **학교 홈페이지 연동**에 게시판 주소를 붙여넣으면 30분마다 **제목·날짜·원문 링크**만 가져옵니다. 본문·첨부파일은 복사하지 않습니다.
- 학부모 화면: 공지 탭 상단 「학교 홈페이지 소식」, 홈 상단에 3일 이내 새 소식 배너, 💬 버튼으로 해당 통신문에 대한 이야기방 바로 만들기
- 그누보드 계열 게시판(`board.php?bo_table=...`)은 RSS → 목록 HTML 순으로 자동 시도, EUC-KR 홈페이지도 지원
- 환경변수로 미리 설정 가능: `NEWS_SOURCES="공지사항|https://...,가정통신문|https://..."`, 주기 `NEWS_INTERVAL_MIN` (기본 30)
- ⚠ 학교 홈페이지가 해외 접속을 막는 경우가 있습니다. 운영자 화면에 「✕ 실패」가 계속 뜨면 **국내 리전 서버**(예: AWS 서울 리전 Lightsail, 네이버클라우드)에 배포하세요.

## 공익 정보 · 제휴(광고) — 공익 우선 원칙
학원·업체 제휴를 받을 수 있지만, 아래 원칙이 **코드로 강제**됩니다.

| 원칙 | 구현 |
|---|---|
| 공익 정보가 먼저 | 목록 정보칸 노출의 최소 70%(`PUBLIC_FIRST_RATIO`)를 공익 정보로 채움. 누적 노출을 보고 자동 조정 |
| 표시·심사 의무 | 운영자만 등록 가능. 제휴는 「제휴」 표시 + 광고주 이름 필수 |
| 대화는 광고 없이 | 대화방(글·댓글) 안에는 광고 없음. 목록 3번째 글 아래 1칸만 |
| 개인 추적 없음 | 노출·클릭은 합계만 집계 (같은 사람 반복 클릭은 1시간에 1회만 집계) |
| 언제든 끄기 | 운영자 화면에서 정보칸 전체 ON/OFF |

- 운영자 화면(더보기)에서 등록·수정·중지·삭제, 게재 기간 설정, 노출·클릭·클릭률 확인 → 광고주 보고용 자료로 활용
- 학부모는 더보기 → **지역·교육 정보**에서 전체 목록과 운영 원칙을 볼 수 있음
- 운영 원칙 문구는 `public/app.js`의 `PROMO_PRINCIPLES`에서 수정

## 주요 기능
| 구분 | 내용 |
|---|---|
| 입장 | 학교가 가정통신문으로 안내한 **입장 코드**만 입력 (회원가입·실명·전화번호 없음) |
| 익명성 | 글마다 무작위 닉네임(예: "다정한 고래"), 댓글은 글 안에서만 `글쓴이 / 익명1 / 익명2…` → 다른 글과 동일인 추적 불가 |
| 개인정보 보호 | 전화번호·이메일·주민번호 자동 가림, IP 미저장, 작성자 식별값은 서버 비밀키로 해시 저장 |
| 말머리 | 공지(운영자 전용) · 자유 · 질문 · 입시·진로 · 건의 · 정보공유 / 검색 / 최신순·공감순 |
| 소통 | 댓글, 공감(♥), 본인 글·댓글 삭제 |
| 자정 기능 | 신고 3회 누적 시 자동 숨김, 비속어 필터, 도배 방지(글 10분 5개 / 댓글 10분 20개) |
| 운영자 | 비밀번호 로그인 → 공지 작성·상단 고정·숨김/해제·삭제, 신고 사유 확인, 주간 현황(말머리별·관심글 TOP5) |

## 실행
```bash
ACCESS_CODE=학부모입장코드 ADMIN_PASSWORD=운영자비번 SCHOOL_NAME="OO초등학교 학부모 소통방" npm start
# → http://localhost:3000
```

| 환경변수 | 설명 | 기본값 |
|---|---|---|
| `ACCESS_CODE` | 학부모 입장 코드 | `1234` (**반드시 변경**) |
| `ADMIN_PASSWORD` | 운영자 비밀번호 | `admin1234` (**반드시 변경**) |
| `SCHOOL_NAME` | 화면 상단 이름 | 동탄국제고 학부모 소통방 |
| `THEME_COLOR` | 학교 상징색 (예: `#1e5aa8`) | `#d7263a` (교표 빨강) |
| `SCHOOL_LOGO` | 로고 경로. `public/logo.png`(또는 .svg/.jpg/.webp)를 넣으면 자동 적용 | 기본 새싹 아이콘 |
| `PUBLIC_FIRST_RATIO` | 정보칸 공익 정보 최소 비율 (0.5~1.0) | 0.7 |
| `PORT` | 포트 | 3000 |
| `DATA_DIR` | DB·비밀키 저장 폴더 | `./data` |
| `REPORT_HIDE_THRESHOLD` | 자동 숨김 신고 수 | 3 |
| `SECURE_COOKIE` | HTTPS 배포 시 `1` | - |

테스트: `npm test`

## 인터넷에 올리기 — Render (해외 서버, 학교 홈페이지 연동이 막힐 수 있음)
1. https://render.com 가입 → GitHub 계정 연결
2. **New + → Blueprint** 선택 → 이 저장소(`jayeonzin`)와 브랜치 선택
3. 입력칸에 `ACCESS_CODE`(학부모 입장 코드), `ADMIN_PASSWORD`(운영자 비번) 입력 → **Apply**
4. 몇 분 뒤 `https://school-parents-board-xxxx.onrender.com` 주소가 생깁니다 → 가정통신문에 안내
   - 비용: Starter 플랜 월 약 $7 + 디스크 1GB 약 $0.25 (글이 지워지지 않도록 영구 디스크 포함)
   - 원하면 Settings → Custom Domain에서 `talk.학교도메인` 같은 주소 연결 가능

그 외 호스팅: `Dockerfile`이 있어 Railway, Fly.io, 학교/회사 서버 어디든 올릴 수 있습니다. 이때 `/data` 폴더를 영구 저장소에 연결하고, HTTPS면 `SECURE_COOKIE=1`을 설정하세요.
